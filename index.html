What you'll walk out able to do

  1. Describe, in one paragraph, how you work on a distributed team: hours, tools, response time, and how your work stays visible.
  2. Write a Done / Doing / Blocked update that a manager can act on without asking a follow-up question.
  3. Run a remote day with five fixed moves: plan, deep work, check-in, handoff, weekly summary.
  4. Name your biggest remote-work risk and the one habit that fixes it.
  5. Point to one remote experience you can start this semester through Elevate.
